# 病棟勤務表（kinmuhyo1027）

病棟看護師の1か月分（1日〜月末）の勤務表を、Webブラウザ上で自動作成するアプリです。
看護師長がスタッフと配置ルールを登録し、看護師が前月のうちに勤務希望を入力します。全員の希望がそろったら「勤務表を作成」を押します。

- 公開中のアプリ: https://claude.ai/artifact/7kxc3UU2dSDW7whxQ8V39J
- 本体: `index.html`（1ファイル。HTML・CSS・JavaScriptのみで、外部ライブラリは使っていません）

## 画面と役割

| タブ | 使う人 | できること |
|---|---|---|
| 勤務表 | 全員 | 師長：希望の提出状況の確認、作成、手直し、公開、CSV保存。看護師：公開された勤務表の閲覧 |
| 希望入力 | 全員 | 日ごと・時間帯（日勤帯／夜勤帯）ごとに「× 勤務できない」「△ できれば避けたい」と自由記載を入力して提出 |
| スタッフ | 師長 | 氏名、入職年数、看護師経験年数、リーダー可否、勤務タイプ（日勤のみ／日勤・夜勤／夜勤中心／夜勤専従）、新人と担当プリセプター、夜勤上限 |
| 配置ルール | 師長 | 曜日別の日勤・夜勤人数、日勤リーダー（日曜は置かない）、プリセプター配置、同時勤務NGの組み合わせ、公休数、連続勤務上限、明けの翌日の扱い |

claude.ai 上では、共有メニューで師長を「編集者」、看護師を「コントリビューター」にして使います。
看護師どうしでは互いの希望は見えません。全員分を見られるのは師長だけです。

## 勤務の前提

- 二交代制です。夜勤の翌日は「明け」になります。
- 休日運用は日曜日です（設定で祝日も含められます）。休日運用の日は日曜の人数で配置し、日勤リーダーは置きません。
- 前月の勤務表がアプリにあれば、月末の夜勤（翌月1日の明け）と連続勤務日数を引き継ぎます。

## 自動作成のしくみ

焼きなまし法（シミュレーテッドアニーリング）で、次の順に重みをつけて組み合わせを探します。

1. 必ず守る：「勤務できない」希望、勤務タイプ、新人の夜勤禁止（設定時）
2. 最優先：配置人数の不足、日勤リーダー、新人と同じ勤務帯のプリセプター、同時勤務NG
3. 次に：公休数、夜勤回数の上限と偏り、連続勤務、明けの翌日の勤務
4. 最後に：「できれば避けたい」希望

満たせなかった条件は「確認が必要な点」に一覧で出ます。マスを押して手で直すこともできます。

## データの保存先

claude.ai のアーティファクト用データベース（`db` 機能）に保存します。

| コレクション | 内容 | 書き込める人 |
|---|---|---|
| `config/settings` | 配置ルール | 師長 |
| `nurses/<id>` | スタッフ名簿 | 師長 |
| `requests/<ユーザーid>`、`requests/mgr-<スタッフid>` | 勤務希望（本人入力／師長の代理入力） | 本人・師長（読めるのも本人と師長だけ） |
| `schedules/<YYYY-MM>` | 作成した勤務表 | 師長 |

`index.html` を claude.ai の外で直接開いた場合は、データをそのブラウザの中だけに保存する「ひとり用」として動きます（共有はされません）。

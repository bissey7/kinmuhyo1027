# 病棟勤務表（kinmuhyo1027）

病棟の看護師・ケアワーカーの1か月分（1日〜月末）の勤務表を、Webブラウザ上で自動作成するアプリです。
病棟ごとに「病棟プロファイル」（配置人数と勤務のルール）を登録しておきます。スタッフの休み希望や勤務指定は Googleフォームで集め、看護師長が回答のCSVをアプリに取り込んで「勤務表を作成」を押します。できた勤務表は印刷して掲示します。

アプリを使うのは師長だけです。看護師・ケアワーカーは Googleフォームに答えるだけで、Claude や Google のアカウントは要りません。

- 公開中のアプリ: https://claude.ai/artifact/7kxc3UU2dSDW7whxQ8V39J
- 本体: `index.html`（1ファイル。HTML・CSS・JavaScriptのみで、外部ライブラリは使っていません）
- Googleフォームを自動で作るプログラム: [`form/create_form.gs`](form/create_form.gs)（Google Apps Script）
- 運用の手順（フォームの作り方・毎月の流れ・取り込み・印刷）: [`docs/operation-guide.md`](docs/operation-guide.md)

## 画面と役割

| タブ | 使う人 | できること |
|---|---|---|
| 勤務表 | 師長 | 希望の受付状況の確認、作成前の見通し、作成、手直し、印刷用ファイルの保存、CSV保存 |
| 希望・指定 | 師長 | Googleフォームの回答CSVの取り込み（全病棟まとめて）、フォーム用の氏名リストの書き出し、一人ずつの確認・代理入力（休み希望、× 不可、△ 避けたい、日勤指定、夜勤指定） |
| スタッフ | 師長 | 職種（看護師／ケアワーカー）、入職・経験年数、リーダー可否、勤務タイプ、夜勤上限、新人と担当プリセプター、配置人数に数えない（育児時短など）、夜勤は指定日のみ、2連休の回数、曜日ごとの決まった条件、並び順 |
| 病棟プロファイル | 師長 | 病棟の登録・名前の変更・並び替え・ルールの複製・削除と、病棟ごとの配置人数（看護師・ケアワーカー別）、夜勤のきまり、休みのきまり、プリセプター、同時勤務NG |

claude.ai 上では、共有メニューで各病棟の師長を「編集者」として招待します。
病棟プロファイルの「希望の集め方」を「スタッフがこのアプリで直接入力する」に切り替えると、第2版と同じく、スタッフが「コントリビューター」としてアプリから入力する運用もできます（Team・Enterprise プラン向け）。

## アプリが決めることと、人が決めること

勤務表には、管理者が頭の中で判断している暗黙の配慮（ライフステージ、家庭の事情、勤務パターンの好み、スタッフどうしの関係など）が多く含まれます。アプリは、**病棟プロファイルに書き出されたルールと優先順位**に沿って下書きを作るところまでを担います。

次の判断は人が行う前提です。アプリには、そのための確認欄と承認の記録があります。
- 労務規定との照合（夜勤回数・連続勤務・休日数など）
- 休暇の種類の選択（公休・有給休暇・特別休暇）
- 勤務帯ごとの組み合わせ（経験・相性）など、パワーバランスの最終調整
- 勤務表の承認

アプリに伝える内容を増やすには、病棟プロファイルの「何を優先するか」や各種の上限、スタッフ情報の曜日ごとの条件、希望・指定を使います。

## 必ず守る条件（自動作成で破られない）

- 休み希望（終日）、勤務指定（日勤・夜勤）、時間帯ごとの「不可」
- 夜勤の上限回数（スタッフごとの個別上限を優先）
- 夜勤入り・明けは1セット。明けの翌日は休み（病棟プロファイルで「必ず」を選んだ場合）
- 夜勤専従者に日勤を入れない。「夜勤は指定日のみ」のスタッフは指定日以外に夜勤を入れない
- 前月末の夜勤の持ち越し（翌月1日は明け、2日は休み）。前月の勤務表がアプリにないときは、「前月末からの引き継ぎ」で師長が指定できる

これらを守ったまま満たせない場合は、勤務表を作る前に「作成前の確認」で知らせます（夜勤の上限の合計が必要数に届かない、日曜・祝日の休みを全員に確保できない、など）。作った後は「確認が必要な点」に、人数不足などとして表示します。

## できるだけ満たす条件（優先順）

1. 配置人数（看護師・ケアワーカー別、配置人数に数えないスタッフを除く）、日勤リーダー、新人と同じ勤務帯のプリセプター、同時勤務NG
2. 公休数、月2回の2連休、日曜・祝日の休み（全員2日以上）、連続勤務の上限、連休の上限（初期値4日。休み希望が続く場合を除く）、夜勤に経験◯年以上を1名
3. 夜勤が月の前半・後半に偏らないこと（差1回以内）、夜勤入りどうしの間隔、日勤・夜勤の方の夜勤回数を均等にすること
4. 「できれば避けたい」の希望

2〜4の重みは、病棟プロファイルの「何を優先するか」で病棟ごとに「重視する／ふつう／控えめ」を選べます。

自動作成には焼きなまし法（シミュレーテッドアニーリング）を使っています。必ず守る条件は、勤務の入れ替えの段階で破る変更を最初から試さないことで守っています。

## データの保存先

claude.ai のアーティファクト用データベース（`db` 機能）に保存します。

| コレクション | 内容 | 書き込める人 |
|---|---|---|
| `wards/<病棟id>` | 病棟プロファイル（病棟名・配置人数・ルール） | 師長 |
| `staff/<スタッフid>` | スタッフ名簿（`wardId` で病棟に所属） | 師長 |
| `requests/<ユーザーid>`、`requests/mgr-<スタッフid>` | 希望・勤務指定（本人入力／師長の代理入力） | 本人・師長（読めるのも本人と師長だけ） |
| `schedules/<病棟id>_<YYYY-MM>` | 作成した勤務表 | 師長 |

`index.html` を claude.ai の外で直接開いた場合は、データをそのブラウザの中だけに保存する「ひとり用」として動きます（共有はされません）。

## 更新履歴

- 第4版：2階病棟での2回目のシミュレーション結果を受けて改修
  - 月またぎの夜勤：前月末日の夜勤入り・明けを師長が指定できる「前月末からの引き継ぎ」
  - 意図しない長い連休を避ける「連休の上限」（休み希望が続く場合は除く）
  - 休暇の種類（公休・有給休暇・特別休暇）。「有給希望」の入力とフォームの列、手直しでの選択、公休数とは別に集計
  - 夜勤に経験◯年以上の看護師を1名置く条件
  - 病棟ごとの「何を優先するか」
  - 最終確認のチェックと承認の記録。印刷用ファイルに承認者と押印欄
  - 作成前の確認に「公休数と配置人数が両立するか」を追加
  - 人数・リーダー・プリセプター・同時勤務NGが、休みの条件より必ず優先されるよう重みを調整

- 第3版：師長だけで運用できる形に変更
  - Googleフォームの回答CSVの取り込み（UTF-8・Shift_JIS 対応、氏名の照合、同じ人の複数回答は最新を採用、矛盾の表示）
  - Googleフォームを自動で作る Apps Script と、名簿に合わせて選択肢を更新する機能
  - 掲示・印刷用ファイル（A3横）の保存
  - 病棟プロファイルに「希望の集め方」（フォーム／アプリ）を追加

- 第2版：2階病棟でのシミュレーション結果を受けて改修
  - 夜勤上限、夜勤入り・明けのセット、明けの翌日の休み、夜勤専従の条件を必ず守るように変更
  - 夜勤の前半・後半の偏りの是正、月2回の2連休、日曜・祝日の休み2日以上を追加
  - 日勤指定・夜勤指定、配置人数に数えないスタッフ、曜日ごとの決まった条件、スタッフの並び順を追加
  - 病棟プロファイル（複数病棟）とケアワーカーの配置を追加
  - 作成前の見通し（条件が両立しない月の事前警告）を追加
- 第1版：最初の版

# Googleフォームで希望を集める運用の手順

看護師・ケアワーカーの希望と勤務指定は Googleフォームで集めます。師長は回答をCSVで勤務表アプリに取り込み、勤務表を作って印刷・掲示します。
アプリを使うのは師長だけです。看護師・ケアワーカーは Google アカウントがなくてもフォームに答えられます。

---

## 最初に一度だけ行うこと

### 1. フォームを作る Google アカウントを決める

個人の Gmail ではなく、**勤務表専用の Google アカウント**を作り、師長間で管理することをおすすめします。異動・退職があってもフォームと回答が残り、職員の事情が個人のアカウントに残りません。
院内の情報管理担当に、このアカウントで運用してよいかを確認しておくと安心です。

### 2. アプリに病棟とスタッフを登録する

1. 勤務表アプリの「病棟プロファイル」で4病棟を登録します。
2. 病棟ごとに、配置人数とルールを設定します。「希望の集め方」は **「Googleフォームで集め、師長がCSVで取り込む」**（初期値）のままにします。
3. 「スタッフ」タブで、病棟ごとに名簿を登録します。**フォームの氏名の選択肢は、この名簿の氏名がそのまま使われます。**

### 3. フォーム用の氏名リストをコピーする

1. アプリの「希望・指定」タブを開きます。
2. 「Googleフォームの回答を取り込む」の右上の **「フォーム用の氏名リスト」** を押します。
3. **「コピー」** を押します。

### 4. フォームを自動で作る

1. 手順1のアカウントでログインし、https://script.google.com を開きます。
2. **「新しいプロジェクト」** を押します。
3. 最初から入っている `function myFunction() {…}` を消し、GitHub の [`form/create_form.gs`](../form/create_form.gs) の中身をすべて貼り付けます。
4. 冒頭の `const WARDS = { … };` の部分（`};` まで）を、手順3でコピーした内容に置き換えます。
5. 上部の保存ボタン（フロッピーの絵）を押します。プロジェクト名は「勤務表フォーム」などで構いません。
6. 上部の関数の選択欄で **`createForm`** を選び、**「実行」** を押します。
7. 初回だけ「承認が必要です」と出ます。
   - 「権限を確認」→ アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「勤務表フォーム（安全ではないページ）に移動」→「許可」
   - 自分で作ったプログラムなので、この表示は問題ありません
8. 画面下の「実行ログ」に、次の3つのURLが出ます。
   - **看護師・ケアワーカーに配るURL**
   - フォームの編集画面
   - 回答のスプレッドシート

   これでフォームと回答用のスプレッドシートができあがりです。URLは、あとで `showUrls` を実行すればもう一度表示できます。

### 5. フォームの設定を一度だけ確認する

フォームの編集画面の「設定」で、次を確認してください。
- 「回答」→「ログインが必要」が**オフ**（Googleアカウントがない人も答えられるように）
- 「回答の編集を許可する」が**オン**（作成プログラムでオンにしてあります）

## 毎月の運用

| 時期 | 師長がすること |
|---|---|
| 前月の上旬 | 回答の受付を開始し、フォームのURLを看護師・ケアワーカーに配る（LINE、院内メール、QRコードの掲示など） |
| 締切日（例：前月20日） | フォームの「回答」タブで「回答を受付中」をオフにする |
| 締切後 | 回答をCSVで保存し、アプリに取り込む → 勤務表を作る → 確認・手直し → 印刷して掲示 |

### 回答の受付の開始と締切

- フォームの編集画面の **「回答」タブ** →「回答を受付中」のオン・オフで切り替えます。
- フォームは毎月同じものを使います。看護師・ケアワーカーは「対象月」で来月を選んで答えます。

### 回答をアプリに取り込む

1. 回答のスプレッドシートを開き、**「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」** で保存します。
2. 勤務表アプリで、右上の月を**対象月**に合わせます。
3. 「希望・指定」タブの **「回答のCSVファイル」** で、保存したファイルを選びます。
4. 一覧で内容を確認します。
   - 「名簿のスタッフ」が空欄の行は、名前が名簿と合わなかった行です。正しい人を選んでください。
   - 同じ人が何度か答えている場合は、いちばん新しい回答だけを取り込みます。
   - 「確認事項」に出た矛盾（例：同じ日に休み希望と日勤指定）は、どちらを優先したかが書いてあります。
5. **「◯名分を取り込む」** を押します。4病棟分がまとめて取り込まれます。
6. 取り込んだ内容は、同じタブの下の「一人ずつの確認・代理入力」で一日ずつ直せます。紙や口頭で受けた希望も、ここで入力できます。

### 勤務表を作って掲示する

1. 「勤務表」タブで公休数を確認し、**「勤務表を作成」** を押します。作成前の確認で条件が両立しない点が出たら、先にプロファイルを見直します。
2. 「確認が必要な点」を見て、必要ならマスを押して手直しします。
3. **「印刷用に保存」** を押し、保存されたファイルをブラウザで開いて **「印刷する」** を押します（A3横。色を付けるには、印刷画面で「背景のグラフィック」をオンにします）。
4. Excel で扱いたいときは「CSVで保存」も使えます。

## 名簿や病棟が変わったとき

### スタッフの入職・退職・異動

1. アプリの「スタッフ」タブで名簿を直します。
2. 「フォーム用の氏名リスト」をコピーし、script.google.com のプログラムの `WARDS` を置き換えて保存します。
3. 関数 **`updateChoices`** を実行します。フォームの氏名の選択肢が新しい名簿に変わります。URLは変わりません。

### 病棟を増やしたとき

病棟の選択肢と氏名のページの組み立てが変わるため、フォームを作り直します。
1. `WARDS` を新しい内容に置き換えて保存します。
2. **`forgetForm`** を実行します。
3. **`createForm`** を実行します。新しいURLを配り直してください。古いフォームは Google ドライブから削除します。

### 対象月の選択肢

作成した月から24か月先までの選択肢が入っています。2年近く使った後は、`updateChoices` を実行すると、その時点から24か月分に更新されます。

## フォームの中身（参考）

| 質問 | 形式 | 備考 |
|---|---|---|
| 対象月 | プルダウン | 「2026年12月」の形 |
| 病棟 | ラジオボタン | 選んだ病棟の氏名ページへ進む |
| 氏名（病棟名） | プルダウン | 病棟ごとのページ |
| 希望・指定 | チェックボックス（グリッド） | 行：1日〜31日、列：休み希望／日勤×／夜勤×／日勤△／夜勤△／日勤指定／夜勤指定 |
| 日勤指定・夜勤指定の理由 | 段落 | 「9日 感染対策委員会」のように1行に1日。勤務表のマスの説明に表示されます |
| 自由記載 | 段落 | 勤務表の「確認が必要な点」の下に表示されます |

質問の名前（「対象月」「氏名（…）」「希望・指定」と、グリッドの列名）はアプリの取り込みと対応しています。フォームの編集画面で**変えないでください**。説明文は自由に変えて構いません。
